# 算法分析
## 知识点
### 概念
1. **特性**
- 有穷性
- 确定性
- 可行性
- 输入
- 输出
2. **时间复杂度**
- T(n) = O(f(n))
- 语句执行的频率
- f(n) = 2n^3 + n^2 + n;
- T(n) = O(n^3);
- 通常讨论最坏时间复杂度
- 代码执行次数为常数时T(n) = O(1);
- ` for(int i = 0;i < n; i++) `执行n+1次,T(n) = O(n);
- 累加和公式 : [n(n+1)(n+2)]/6;(立方阶)
- `for(int i= 0;i < n;i = i*2)` 2^(t-1) > n,t >log2(n+1);(对数阶)
3. 空间复杂度
- 除了存储代码和输入数据外,还需要的额外空间
4. ADT(抽象数据类型)
