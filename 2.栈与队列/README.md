# 栈与队列
## 栈
### 定义与实现
1. 定义
- 有特殊规则的线性表
- 栈（stack）是限定仅在表尾进行插入或者删除的线性表
- 表尾为栈顶（top），表头为栈底（bottom）
- 后进先出
- 进栈（push），出栈（pop）
2. 实现
- 有顺序结构和链式结构
- 代码实现在`Stack(list).c`和`Stack(node).c`文件
## 队列
### 定义与实现
1. 定义
- 队列（queue）是先进先出的线性表
- 队尾（rear）**指向队尾元素下一个位置**
- 队头（front）**指向队头位置**
2. 实现
- 顺式结构代码实现在`Queue(list).c`
- 链式结构实现在`Queue(node).c`
## 思考🤔
1. 队列（queue）入队时要考虑队列满没满，没满时需要横移队列
2. 队列（queue）——链式结构需要定义两个结构体（但不是硬性要求），方便管理队头与队尾
