# 线性表
## 线性表的定义与特点
1. 定义
- n个相同数据类型的数据元素的有限序列(集合,数组)
2. 特点
- 有头有尾
- 有唯一前驱与后继
--- 
图书管理系统,需要很多书,并进行操作则需要线性表
代码示例见`1.1.c`文件
## 线性表的顺序表示与实现(顺式表)
1. 定义
- 用一组连续的内存单元一次存储线性表各个元素,逻辑上相邻的元素,物理存储空间也是连续的
2. 代码
- 代码实现在`SeqList.c`文件
3. 时间复杂度
- O(n)
4. 总结
- 实现了顺序表,完成增删改查等功能
- 删除和插入很麻烦,需要链表来改进
## 线性表的链式表示与实现(链表)
1. 实现
- 单向链表代码实现在`Singly_Node_List.c`文件
- 双向链表一个指向前驱,一个指向后继
- 双向链表代码实现在`Doubly_Node_List.c`文件
2. 总结
- 实现了链表,完成增删改查等功能
- 每个节点指向下个节点地址
3. 例题
- 学习了快慢指针

## 对比
- 空间：顺序表预先分配有溢出或者闲置，链表动态分配
- 时间：顺序表按位置访问时间复杂度o（1），插入删除时间复杂度o（n）；链表顺序存取时间复杂度o（n），插入删除时间复杂度o（1）；
