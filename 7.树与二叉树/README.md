# 树与二叉树
## 树
1. 概念
- 结点：树中的一个独立单元
- 结点的度：结点拥有的子树数
- 树的度：结点度的最大值
- 叶子：度为0的结点
- 层次：结点的层次从根开始定义
2. 基本性质
- 树中所有结点数等于所有结点的度数之和加1
- 对于度为m的树，第i层上最多有m^i-1个结点
- 对于高度为h，度为m的树，最多有（m^h-1）/(m-1)个结点
## 二叉树
1. 概念
- 有且仅有一个称为根的结点
- 每个结点至多有两棵子树
- 二叉树的子树有左右之分
2. 性质
- 第i层最多有2^(i-1)个结点
- 深度为k的二叉树最多有(2^k)-1个结点
- 对于任何非空的二叉树，叶子结点为n个，度为2的结点为m个，n=m+1；
3. 特殊二叉树
- 满二叉树：深度为k，结点数为(2^k)-1个；
- 完全二叉树：没有左子树，不能有右子树，上一层没有铺满，不能有下一层
  - 性质：具有n个结点的完全二叉树，神度为log2n+1（向下取整）；
4. 代码实现
- 二叉树的顺式结构，有空的存在，会浪费空间
- 二叉树的链式结构实现在文件`binary-tree(node).c`中，实现了二叉树的创造以及前中后序遍历
5. 遍历
- 前序和中序遍历可以确定一棵二叉树
- 中序和后序遍历可以确定一棵二叉树
- 后序和前序遍历不能确定一棵二叉树
## 线索二叉树
1. 概念
- 为了知道前中后序遍历后某个结点的下一个结点
- 创建ltag与rtag，为0时候指向左（右）孩子，为1时候为前（后）驱线索
2. 中序遍历线索化
- 头结点的lchild指向二叉树的根
- 头结点的rchild指向遍历的最后一个结点
- 遍历后的第一个结点的lchild指向头结点
- 遍历后最后一个结点的rchild指向头结点

1. 二级指针**T
- T为地址后逐层解地址
2. &（取地址）的优先级小于->
- &[(*T)->lchild]=&(*T)->lchild
